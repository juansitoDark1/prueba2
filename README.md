# ✨ Task Manager Application

A beautiful, modern task manager built with vanilla JavaScript, HTML, and CSS.

## Features

- ✅ Add, complete, and delete tasks
- 🎨 Beautiful gradient UI with smooth animations
- 🔍 Filter tasks by All, Active, or Completed
- 💾 Persistent storage using localStorage
- 📱 Fully responsive design
- ⚡ Fast and lightweight (no frameworks needed)

## How to Use

1. Open [`index.html`](index.html:1) in your web browser
2. Type a task in the input field
3. Click "Add Task" or press Enter
4. Check the checkbox to mark tasks as complete
5. Use the filter buttons to view different task categories
6. Click "Delete" to remove individual tasks
7. Click "Clear Completed" to remove all completed tasks

## Files

- [`index.html`](index.html:1) - Main HTML structure
- [`styles.css`](styles.css:1) - Styling and animations
- [`script.js`](script.js:1) - Task management logic

## Technologies

- HTML5
- CSS3 (with animations and gradients)
- Vanilla JavaScript (ES6+)
- LocalStorage API
